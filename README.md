# 周末有空 · H5

一个发到微信群里的周末半天空闲收集页：大家点选周六/周日 × 上午/下午，页面实时汇总；周五 20:00 之后组织者把同一个链接再发一次群即可。

不需要小程序 AppID、不需要云开发、不需要体验成员；一个 Node 进程 + 一个 JSON 文件就是后台。

## 本地跑起来

需要 Node 18+（当前机器是 Node 22）。

```bash
npm start
```

打开 <http://localhost:4173>。

1. 第一次打开会弹出昵称输入。
2. 填完后点四个半天卡片，点一下即存。
3. 页面 URL 会变成 `/r/<房间号>`；点「复制群链接」，把链接发到群里。
4. 同一链接长期复用；周一自动切到新一周。

## 手机本地测试

- 手机和电脑连同一个 Wi-Fi。
- 终端启动时会打印「局域网: http://192.168.x.x:4173」，用手机浏览器或微信打开这个地址。
- Windows 防火墙弹窗要允许 Node。
- 在手机上打开后再点「复制群链接」，复制到的才是手机能访问的地址；`localhost` 链接只在这台电脑有效。

## 怎么工作

- **房间**：链接 `/r/<roomId>`；谁拿到链接谁就能加入，没有群成员名单。
- **身份**：昵称 + 浏览器 localStorage 里的随机 ID。没有微信登录、没有 openid。换手机或清缓存会变成新成员。
- **四格**：周六上午/下午、周日上午/下午；点一下即存。
- **结果**：全员有空优先；否则显示人数最多的时段、还差谁、还有谁没填。
- **周五**：页面结果是实时计算的；20:00 之后保存会标记「补」。没有自动推送，组织者周五打开链接、把同一个链接再发一次群。
- **数据**：`data/store.json`。首次启动自动创建；备份这个文件即可。

## 部署到阿里云 ECS

### 最省事：先 HTTP + 公网 IP

1. ECS 安装 Node 18+，把整个目录拷上去。
2. 在目录里运行：

```bash
nohup npm start > weekend-free.log 2>&1 &
```

或者用 systemd/pm2 常驻。

3. 阿里云安全组放行 `4173` 端口。
4. 链接：`http://<公网IP>:4173`。

微信打开 HTTP/IP 链接时可能提示「非官方网页/不安全」，点继续可以进。这只适合小范围实验，不建议长期公开使用。

### 免费 HTTPS：Cloudflare Tunnel

如果不想买域名，可以在 ECS 上装 `cloudflared`，把本地 4173 暴露成一个 HTTPS 地址：

```bash
cloudflared tunnel --url http://localhost:4173
```

它会输出一个 `https://xxxx.trycloudflare.com` 地址，用这个发群。不需要域名/备案，适合一周实验；但进程或 ECS 重启后 URL 可能变，需要重新发群。

### 长期稳定：域名 + ICP备案 + HTTPS

1. 域名（几十元/年）+ 国内 ECS 做 ICP 备案（免费，但按周计）。
2. 免费 SSL 证书（阿里云免费证书或 Let's Encrypt）。
3. Nginx 反代到 `127.0.0.1:4173`，对外用 `https://yourdomain.com`。
4. 群链接固定，不再变化。

国内 ECS 对外提供网站服务，合规上仍然需要 ICP 备案；H5 只是绕开了小程序的 `request 合法域名` 校验，不是绕开备案。

## 已知限制

- 没有微信身份/服务通知；昵称 + localStorage。
- 清缓存/换设备会变成新成员。
- 任何人拿到链接都能加入；没有踢人/成员名单。
- 只显示当前周，没有历史周视图。
- 按北京时间计算周末；不识别法定节假日和调休。
- HTTP/IP 链接微信可能提示风险；长期使用建议备案域名 + HTTPS。

原来的微信小程序/云开发版本已按你的要求移除；周末计算、统计、结果文案这些纯逻辑保留并复用到了 `server/lib`。
